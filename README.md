# wardley-mermaid-vitepress

Using VitePress to render [tractorjuice/wardley-maps-mermaid](https://github.com/tractorjuice/wardley-maps-mermaid), which is based on [swardley/WARDLEY-MAP-REPOSITORY](https://github.com/swardley/WARDLEY-MAP-REPOSITORY).

https://rosano.github.io/wardley-mermaid-vitepress/

# Setup

Run `setup.sh`:

```
bash setup.sh
```

# Run

Start a web server which reloads on change:

```
npm start
```
